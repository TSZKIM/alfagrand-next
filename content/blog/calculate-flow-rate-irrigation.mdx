# Q&A: Calculating Flow Rate for Irrigation Pumps

**Question**: *"I need to set up an irrigation system for my 2-hectare farm. How do I calculate the right flow rate and head for my irrigation pump?"*

This is one of the most common questions we receive from agricultural customers. Here's a step-by-step guide with practical examples.

## Step 1: Determine Your Water Requirement

First, calculate how much water your crops need:

```
Daily water requirement (m³/day) = Crop water need (mm/day) × Area (m²) / 1000
```

**Example**: For a 2-hectare (20,000 m²) vegetable farm requiring 5 mm/day:
```
Daily water = 5 × 20,000 / 1000 = 100 m³/day
```

## Step 2: Determine Operating Hours

Based on your irrigation schedule. Most farmers irrigate 6-8 hours per day.

**Required flow rate**:
```
Flow rate (m³/h) = Daily water requirement / Operating hours
```

**Example** (8 hours operation):
```
Flow rate = 100 / 8 = 12.5 m³/h
```

## Step 3: System Efficiency Factor

Account for system losses (typically 15-25%):

```
Actual flow required = Required flow / System efficiency
```

**Example** (80% efficiency):
```
Actual flow = 12.5 / 0.8 = 15.6 m³/h
```

## Step 4: Calculate Total Head

Total head includes:

1. **Suction lift**: Vertical distance from water level to pump (e.g., 5m)
2. **Discharge head**: Vertical distance from pump to highest point (e.g., 20m)
3. **Friction loss**: Pipe friction (estimate 15-20% of static head, ≈ 5m)
4. **Sprinkler pressure**: Required at sprinkler head (e.g., 30m or 3 bar)

```
Total head = 5 + 20 + 5 + 30 = 60m
```

- Consider future expansion when sizing pumps
